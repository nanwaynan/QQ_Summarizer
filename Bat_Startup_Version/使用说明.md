# QQ 群聊总结器 —— 文件夹版（bat 启动）使用说明

> **这一版适合谁**：大多数用户。双击一个 bat 就能用，不需要安装 Python。

---

## 第 1 步：确认目录完整

本目录下应该有以下内容：

```
Bat_Startup_Version\
├── 启动.bat              ← 双击这个
├── 使用说明.md            ← 本文件
├── README.md             ← 项目总说明
├── config.example.json   ← 配置模板
├── 文件夹版\
│   ├── QQ总结器.exe
│   └── _internal\        ← 必须有，和 exe 同目录
└── napcat_green\         ← NapCat，拉 QQ 消息必需
```

如果缺少 `文件夹版\_internal`，程序无法启动，请重新获取完整的发布包。

## 第 2 步：双击「启动.bat」

程序界面会打开。首次启动约 1-3 秒。

## 第 3 步：按引导配置

首次启动会弹三步引导：

1. **配置 AI 接口** —— 填 Base URL、模型名、API Key
2. **启动服务并登录 QQ** —— 会弹 UAC 提权，点「是」，然后用手机 QQ 扫码登录
3. **选择要总结的群**

## 第 4 步：开始总结

回到「手动总结」页，选时间段，点「开始总结」。

---

## 前置条件

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11（64 位） |
| QQ 客户端 | 推荐 QQ NT 9.9.25 及以上 |
| AI 接口 | OpenAI 兼容，能访问网络 |
| 管理员权限 | 注入 QQ 需要，首次启动服务会弹 UAC |

**不需要**：Python、Node.js。

---

## 第一次使用会遇到的弹窗

### 1. Windows 智能屏幕筛选器

> "Windows 已保护你的电脑"

点「**更多信息**」→「**仍要运行**」

原因：exe 没有代码签名证书，这是 Windows 的默认提示。

### 2. UAC 用户账户控制

> "是否允许此应用对你的设备进行更改"

点「**是**」

原因：NapCat 需要管理员权限才能注入 QQ 客户端。

这两个弹窗都只在第一次运行时出现。

---

## NapCat 首次登录

程序会自动启动内置的 NapCat，但需要你用手机 QQ 扫码：

1. 程序界面会显示二维码
2. 打开手机 QQ → 扫一扫 → 扫描
3. 手机上点「确认登录」
4. 程序自动完成初始化，服务状态变绿

登录态会保存在本机，之后一般不用重复扫码。如果换了电脑、或 QQ 登录态失效，才需要重新扫。

## 配置在哪改

程序界面 → 左侧「设置」页。

| 配置项 | 说明 |
|---|---|
| 接口地址（Base URL） | AI 服务的 API 根地址 |
| 模型名称 | 具体模型 ID |
| API Key | **必须填你自己的**，模板里的 `YOUR_API_KEY_HERE` 不可用 |
| QQ 账号 | 可切换，切换会重启 NapCat 约 1-3 分钟 |
| 群聊选择 | 可多选 + 搜索 |
| 输出目录 | 默认 `桌面\QQ记录` |
| 总结模式 | 「文字 + 图片」/「仅文字」 |
| 图片数量上限、最低分 | 控制图片甄选 |
| 主题 | 跟随系统 / 浅色 / 深色 |

改完点「保存设置」，立即生效。

## 输出在哪

默认 `桌面\QQ记录\`：

```
QQ记录\
├── 261014\               ← 按日期命名（26年10月14日）
│   ├── 261014.md         ← 总结正文
│   └── images\           ← AI 甄选的图片
└── 261013\
    └── 261013.md
```

「一天」的口径是：**当天 12:00 到次日 12:00**。

例如 `261014.md` 覆盖 10月14日 12:00 ~ 10月15日 12:00。

可以在「设置」页改输出目录，或点「打开输出目录」快速跳转。

## 常见问题

### 双击启动.bat 提示找不到 exe

检查 `文件夹版\QQ总结器.exe` 是否存在。如果整个 `文件夹版` 文件夹被误删，需要重新获取发布包。

### 程序启动后立刻消失

可能已有一个实例在运行（程序限制单实例）。看屏幕右下角系统托盘，双击图标可恢复窗口。

### 服务状态是红点「NapCat 未运行」

点服务卡片上的「启动服务」按钮。会弹 UAC，点「是」，等 1-3 分钟。

### 点了启动服务，一直转圈没反应

1. 检查是否有 UAC 弹窗被最小化或藏在后面，点「是」
2. 如果确实点了还是不行，到任务管理器结束所有 `QQ.exe` 进程，再点「重新检查」重试

### 提示「请用手机 QQ 扫码登录」但没有二维码

等几秒，二维码是异步生成的。

如果一直不出，关闭程序，手动运行 `napcat_green\启动NapCat.bat` 看看有没有报错。

### QQ 登录失败 / 提示风控

用手机 QQ 登录一次该账号，完成安全验证，再回到程序重试。

QQ 版本过新也可能导致 NapCat 不兼容，可以降级到 9.9.25 ~ 9.9.36 范围。

### API 报错 / 额度不足

「设置」页点「测试连接」看具体错误。检查 Base URL 结尾有没有 `/v1`、模型名是否正确、Key 是否有效。

### 数据不完整警告

NapCat 只在运行期间才能记录消息。你离线那段时间的消息拿不到。

解决办法：让 NapCat 常驻（开启开机自启）。

### 图片很少或没有

两个原因：

1. **模型不支持视觉输入** → 换支持图片的模型，或把总结模式改为「仅文字」
2. **图片评分都没达到门槛** → 设置页把「图片最低分」从 4 调到 3 试试

### 切换账号时弹出黑色的命令行窗口

正常情况下不会有可见窗口（程序用了隐藏启动器）。

如果看到了，检查 `napcat_green\launch_hidden.vbs` 是否存在。该文件负责提权 + 隐藏。

### 中文显示成方块

系统缺少「微软雅黑」字体。

---

## 卸载

直接删除整个 `Bat_Startup_Version` 文件夹即可。

程序不在注册表留东西，除非你开了开机自启 —— 那会在 `HKCU\...\Run` 里留一个 `QQSummarizer` 键，在「自动任务」页关掉自启就会删除。
