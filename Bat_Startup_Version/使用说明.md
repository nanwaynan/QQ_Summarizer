# QQ 群聊总结器 —— 使用说明

> **三分钟上手**。每一步都写了「怎么确认这步成功了」，卡住时直接跳到最后一章「出问题了怎么办」。

---

## 这个程序是干什么的

把你 QQ 群里一天的聊天记录拉下来，让 AI 总结成一份日报，存到你电脑上。
**只读**：不会往群里发消息，不会上传你的聊天记录。

---

## 开始前：确认两样东西

| 需要什么 | 怎么确认 |
|---|---|
| **QQ 电脑版** | 打开 QQ 能正常登录就行。推荐 9.9.25 ~ 9.9.36 版本（程序「使用帮助」页会自动检测） |
| **一个 AI 接口** | 就是能调用大模型的地址 + 一个 Key。没有的话可以用免费的本地模型，见第 3 步 |

**不需要**：Python、Node.js、任何开发环境。

---

## 第 1 步：解压

1. 把下载的 `Bat_Startup_Version.zip` **解压**到一个你找得到的地方
   - 建议解压到 `D:\QQ总结器\` 这类**简单路径**
   - ⚠️ **不要**解压到 `C:\Program Files`（需要管理员权限，配置存不进去）
   - ⚠️ 路径里**不要有** `%`、`#` 这类符号
2. 解压后应该是一个文件夹，里面有这些东西：

```
你的文件夹\
├── 启动.bat            ← 双击这个启动
├── QQ总结器.exe        ← 主程序（不要单独拷走）
├── _internal\          ← 运行库（必须有，不能删）
├── napcat_green\       ← 读 QQ 消息用的组件（必须有，不能删）
├── config.example.json ← 配置模板（不用管）
└── 使用说明.md         ← 本文件
```

> ✅ **这步成功的标志**：能看到 `启动.bat` 和 `QQ总结器.exe` 在同一个文件夹里。
> ❌ **如果只看到 exe、没有 `_internal`**：解压不完整，重新解压。

---

## 第 2 步：双击启动

双击 **`启动.bat`**。

会弹出一个黑色窗口，自动检查文件是否齐全：

- 显示 `[OK] 文件检查通过` → 正常，程序界面马上会打开
- 显示 `[X] 缺少...` → **窗口会告诉你缺什么**，按提示重新解压

黑色窗口显示「正在启动...」后可以**直接关掉**，不影响程序运行。

> ✅ **这步成功的标志**：看到程序主界面（左边有一列图标：首页、自动任务、设置、日志）。
>
> ⚠️ **第一次启动可能遇到两个弹窗，都是正常的**：
> - 「Windows 已保护你的电脑」→ 点「**更多信息**」→「**仍要运行**」
> - 「你要允许此应用对你的设备进行更改吗」→ 点「**是**」
>
> 原因：exe 没有数字签名证书，Windows 对未签名程序都会这样提示。

## 第 3 步：配置 AI 接口（必做）

程序首次启动会自动弹出**欢迎引导窗口**。如果没弹，点左侧「**设置**」图标。

### 填写三个字段

| 字段 | 填什么 | 例子 |
|---|---|---|
| **接口地址** | AI 服务的 API 地址 | `https://api.openai.com/v1` |
| **模型名称** | 你想用的模型 | `gpt-4o-mini` |
| **API Key** | 你的密钥 | `sk-xxxxxxxx` |

### 填完必须点「测试连接」

- 显示 `✓ 连接成功 · 1.23s · 回复：...` → **成功，进入下一步**
- 显示 `✗ ...` → 看后面的错误文字，对照下表

| 测试连接报错 | 原因 | 怎么办 |
|---|---|---|
| `401` / `Unauthorized` / `invalid api key` | Key 填错或已失效 | 重新复制 Key，注意别多复制空格 |
| `403` | Key 没有该模型的权限 | 换模型名，或换一个 Key |
| `404` / `model not found` | 模型名写错 | 检查拼写，要和服务商给的一模一样 |
| `连接超时` / `timed out` | 网络到不了 | 检查网络、代理；国内访问 OpenAI 通常需要代理 |
| `额度不足` / `insufficient` | 账户没钱了 | 充值或换 Key |

> 💡 **没有 API Key？** 用本地模型（免费）：
> 1. 安装 [Ollama](https://ollama.com/)
> 2. 命令行运行 `ollama run qwen2.5:7b`
> 3. 程序里接口地址填 `http://127.0.0.1:11434/v1`，模型名填 `qwen2.5:7b`，Key 随便填 `x`
>
> ⚠️ 本地模型要**支持图片理解**才能用图片甄选功能，否则请把总结模式改成「仅文字」。

### 填完记得保存

**点「保存设置」**。不点的话切走页面会提示你有未保存的修改。

> ✅ **这步成功的标志**：「测试连接」显示成功，并且点了「保存设置」。

## 第 4 步：启动服务并登录 QQ（必做，最容易卡住）

回到左侧「**手动总结**」页，看顶部那张服务状态卡片。

### 正常流程

1. 程序启动时会**自动尝试拉起 NapCat**（状态显示「正在启动 NapCat（N 秒）...」）
2. 弹出 UAC 提权窗口 → 点「**是**」
3. 程序会自动关闭已登录的 QQ，然后带着 NapCat 重新启动 QQ
4. 等 30~90 秒，程序弹出**二维码窗口**
5. 打开手机 QQ → 扫一扫 → 扫描屏幕上的码
6. 手机上点「**确认登录**」
7. 状态变成绿点 **`服务正常 · 已登录 你的昵称 (QQ号)`**

> ✅ **这步成功的标志**：服务状态是**绿色圆点**，文字是「服务正常 · 已登录 xxx」。
> 这一行绿字出现之前，**不要**往下走，否则群列表一定加载失败。

### 状态卡片各种颜色是什么意思

| 显示 | 含义 | 你要做什么 |
|---|---|---|
| ⚪ 灰点「正在检查服务状态...」 | 正在检测 | 等 3~5 秒 |
| 🔴 红点「NapCat 未运行」 | 服务没起来 | 点「**启动服务**」按钮 |
| 🟡 黄点「NapCat 已启动，但 QQ 未登录」 | 服务在跑，要扫码 | 点「**扫码登录**」 |
| 🟢 绿点「服务正常 · 已登录 xxx」 | **一切就绪** | 继续下一步 |

### ⚠️ 如果一直停在「正在启动 NapCat（N 秒）」

程序等满 180 秒后不会只报「超时」，而是会告诉你**具体卡在哪一步**：

| 程序告诉你的原因 | 实际发生了什么 | 怎么办 |
|---|---|---|
| **注入器进程没有在运行** | 启动脚本没被执行 | ① UAC 窗口是不是点了「否」？重来点「是」<br>② 杀毒软件拦截 → 把整个文件夹加入白名单<br>③ 重试 |
| **注入器在运行，但 QQ 没有被启动** | 找不到 QQ 客户端 | ① 确认 QQ 已安装并能正常打开<br>② 把 `QQ.exe` 拖到 `napcat_green\启动NapCat.bat` 上（会自动记住路径） |
| **QQ 在运行，但注入器已退出** | 注入失败 | ① 完全退出 QQ（含右下角托盘图标）再试<br>② 关闭其他 QQ 插件（防撤回、美化包等）<br>③ 检查 QQ 版本是否过新 |
| **注入器和 QQ 都在，但 NapCat 没加载** | 注入未生效 | ① 完全退出 QQ 后重试<br>② 关闭其他注入类工具<br>③ 更换 QQ 版本（推荐 9.9.25 ~ 9.9.36） |

### 手动兜底方案（自动启动一直失败时）

1. 打开文件夹 `napcat_green`
2. **双击 `启动NapCat.bat`**
3. 命令行窗口里会显示**具体卡在哪一步**，按提示处理
4. 看到扫码提示后，回到程序点「**重新检查**」

> 手动能起来，说明 NapCat 本身没问题，问题在权限或路径上；
> 手动也起不来，命令行窗口里的报错就是根本原因。

## 第 5 步：选择要总结的群（必做）

左侧「**设置**」页 → 找到「**群聊选择**」区域。

1. 点右上角「**刷新列表**」
2. 出现群列表后，用搜索框找你的群
3. **勾选**你要总结的群（可以多选）
4. 滚到底部，点「**保存设置**」

> ⚠️ **如果显示「无法连接 NapCat —— 服务还没启动」**：
> 说明第 4 步还没做完。点那个区域出现的「**启动 NapCat 服务**」按钮，
> 或者回到「手动总结」页点「启动服务」，等绿点出现后再回来刷新。
>
> ⚠️ **如果显示「共 0 个群」**：这个 QQ 号还没加任何群，或者换个号登录试试。

> ✅ **这步成功的标志**：群列表里能看到群名和群号，勾选后点了「保存设置」。

---

## 第 6 步：开始总结

回到「**手动总结**」页：

1. **选时间段**
   - 直接点快捷按钮最省事：「**昨天12点起**」（符合每日归档习惯）
   - 或手动选「从 / 到」，跨度不能超过 24 小时
2. 点「**开始总结**」
3. 看下方「运行日志」的实时进度
4. 完成后点「**打开输出目录**」看结果

### 输出在哪

默认在 **桌面\QQ记录\**，按日期分文件夹，里面是 `.md` 文件（Markdown 格式，记事本能打开）。

想改位置：「设置」页 →「输出目录」→「浏览」→ 选新目录 → 保存。

> ✅ **这步成功的标志**：输出目录里出现 `.md` 文件，打开能看到「概览」「主要话题」「精彩发言」等章节。

---

## 想让程序每天自动总结？

左侧「**自动任务**」页：

1. 打开「启用自动任务」开关
2. 设置每天几点执行（默认 12:30）
3. 选择要总结的群（默认跟随「设置」页的选择）
4. 点「保存设置」

> 💡 改完开关或时间**立即生效**，不需要重启程序。
> 💡 「错过补跑」只在**下次启动程序**时检查一次，不会在后台立即补跑。

---

## 日常使用只需要两步

配置好一次之后，以后每天：

1. 双击 `启动.bat`（或者让它开机自启）
2. 点「开始总结」

程序会记住你的 AI 配置、群选择、时间段。

## 出问题了怎么办

### 先做这三件事

1. **看「运行日志」区域**——具体错误会写在这里，比任何猜测都准
2. **看「使用帮助」页**——它会检测你的 QQ 版本和 NapCat 状态
3. **手动双击 `napcat_green\启动NapCat.bat`**——命令行会显示最原始的错误

### 常见问题速查

| 症状 | 原因 | 解决 |
|---|---|---|
| 双击 启动.bat 一闪就没了 | 文件不全，或已有实例在托盘 | 看黑窗口提示；检查右下角托盘有没有图标 |
| 提示缺少 `python312.dll` / `VCRUNTIME140.dll` | `_internal` 不完整 | 重新解压整个包，别只拷 exe |
| 提示「Windows 已保护你的电脑」 | 未签名程序的正常提示 | 更多信息 → 仍要运行 |
| 界面是空白 | 显卡驱动 / Qt 渲染问题 | 更新显卡驱动；远程桌面时可关掉硬件加速 |
| 中文显示成方块 | 系统缺中文字体 | 安装「微软雅黑」字体 |
| 主题切换后有的地方还是黑的 | **v1.0.4 已修复** | 升级到最新版 |
| 引导窗口点「下一步」就关了 | **v1.0.4 已修复** | 升级到最新版 |
| 服务一直转圈 | 见第 4 步的分层诊断表 | 按程序给出的原因处理 |
| 二维码出不来 | NapCat 还没到扫码阶段 | 多等一会；或手动启动 NapCat 看报错 |
| 登录提示风控 / 错误码 168 | QQ 限制新设备登录 | 换个时间段；或直接在手机上确认登录 |
| 图片很少或没有 | 模型不支持视觉 | 换支持图片理解的模型，或改为「仅文字」 |
| 总结内容空洞 | 模型能力不足 | 换更强的模型（如 GPT-4o、Claude 系列） |
| 找不到输出文件 | 默认在桌面\QQ记录 | 「设置」页看「输出目录」 |

### 还是要提问？

去 GitHub 提 Issue 时，请附上：

- 「运行日志」区域的完整内容（API Key 会自动打码，可放心贴）
- 你的 QQ 版本（「使用帮助」页能看到）
- 具体卡在哪一步

只说「用不了」很难帮你定位问题。

## 安全与隐私

- **只读**：不会往群里发消息，不会修改你的 QQ 数据
- **不上传**：聊天记录只存在你电脑上，除了发送给**你自己配置的 AI 服务**之外不发往任何地方
- **API Key**：只存在本地 `config.json`，日志里自动打码成 `sk-a****wxyz`
- **NapCat**：通过注入本机 QQ 读取消息，本质上是把 QQ 变成一个可读取的接口，请自行评估风险

## 目录里每个文件是干什么的

| 文件 / 目录 | 作用 | 能删吗 |
|---|---|---|
| `启动.bat` | 启动器，做文件自检后拉起程序 | 不能 |
| `QQ总结器.exe` | 主程序 | 不能 |
| `_internal\` | Python 运行库，exe 依赖它 | **绝对不能** |
| `napcat_green\` | 读 QQ 消息的组件 | **绝对不能** |
| `config.json` | 你的配置（首次运行后自动生成） | 能，但配置会丢 |
| `config.example.json` | 配置模板 | 能，没用 |
| `logs\app.log` | 运行日志 | 能，排查问题用 |
| `使用说明.md` | 本文件 | 能 |
