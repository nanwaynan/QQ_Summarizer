# QQ 群聊总结器 —— 单文件版 使用说明

> **这一版适合谁**：想把它拷到 U 盘 / 发给别人的人。只有一个 exe，最便于分发。

---

## 和文件夹版的区别

| | 单文件版 | 文件夹版 |
|---|---|---|
| 文件形态 | 一个 exe（48 MB） | exe + `_internal`（117 MB） |
| 首次启动 | 需自解压，5-15 秒 | 1-3 秒 |
| 便于分发 | ✅ 一个文件 | ⚠️ 要拷整个文件夹 |
| 功能 | 完全一样 | 完全一样 |

如果你只是自己用，推荐文件夹版（启动更快）。

---

## 第 1 步：确认目录完整

```
EXE_Single_File_Version\
├── QQ总结器.exe        ← 双击这个
├── 启动.bat            ← 或者双击这个
├── 使用说明.md          ← 本文件
├── README.md           ← 项目总说明
├── config.example.json
└── napcat_green\       ← 必需，别删
```

> ⚠️ `napcat_green` 文件夹不能少，否则程序能开但拉不到 QQ 消息。

## 第 2 步：双击「QQ总结器.exe」

首次启动会自解压，等 **5-15 秒**，界面就出来了。之后再启动会快一些。

## 第 3 步：按引导配置

三步引导：配置 AI 接口 → 启动服务并扫码 → 选择群聊。

## 第 4 步：开始总结

「手动总结」页，选时间段，点「开始总结」。

---

## 前置条件

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11（64 位） |
| QQ 客户端 | 推荐 9.9.25 及以上 |
| AI 接口 | OpenAI 兼容 |
| 管理员权限 | 首次启动服务会弹 UAC |

**不需要**：Python、Node.js。

---

## 第一次使用会遇到的弹窗

### 1. 智能屏幕筛选器

> "Windows 已保护你的电脑"

点「更多信息」→「仍要运行」。

### 2. UAC 用户账户控制

点「是」。

### 3. 自解压进度条

单文件版首次启动时可能短暂出现一个进度条窗口 —— 正常现象，等它消失即可。

---

## 配置说明

界面 → 左侧「设置」页：

- **AI 配置**：Base URL / 模型名 / API Key（必填）
- **QQ 账号 / 群聊选择**
- **存储与其他**：输出目录、总结模式、图片设置、主题

> ⚠️ 模板里的 `YOUR_API_KEY_HERE` 是占位符，必须换成你自己的真实 Key，否则会报鉴权失败。

配置文件 `config.json` 会生成在 exe 同目录，首次运行自动创建，不用手动建。

---

## 输出位置

默认 `桌面\QQ记录\261014\261014.md`（+ `images\`）。

时间口径：当天 12:00 ~ 次日 12:00 记为一天。可在「设置」页改输出目录。

## 常见问题

### 双击后等很久都没反应

单文件版首次启动要解压，等 15 秒左右。

如果超过 1 分钟，打开任务管理器看有没有 `QQ总结器.exe` 在跑。有的话再等等。

### 提示缺少 python312.dll 之类

单文件解压不完整，通常是杀软拦截导致的。

把 exe 加到杀软白名单，或改用文件夹版。

### 程序启动后立刻消失

已有实例在运行（单实例限制）。看系统托盘，双击图标恢复。

### 服务状态红点

NapCat 没运行，点「启动服务」→ UAC 点「是」。

### 拉不到消息 / 只有几条

NapCat 只在运行期间记录消息，离线时段拿不到。让 NapCat 常驻可避免。

另外确认 `napcat_green` 文件夹在 exe 同目录下。

### API 报错

检查 Key 是否填了真实值（不是 `YOUR_API_KEY_HERE`）、Base URL 是否正确、账户是否有额度。

### 图片很少

模型可能不支持看图。换多模态模型，或把总结模式改成「仅文字」。

### 想把配置和程序一起拷到别的电脑

拷整个 `EXE_Single_File_Version` 文件夹（exe + napcat_green + config.json）。

只拷 exe 的话，换机器后要重新扫码登录 QQ。

---

## 卸载

删除整个 `EXE_Single_File_Version` 文件夹。

如果想彻底清干净，还要删掉：

- 本机的 QQ 登录态（在 QQ 客户端里退出登录）
- 开机自启注册表项（如果开过，在程序里关掉即可）
