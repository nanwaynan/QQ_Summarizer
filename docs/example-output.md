## 主要话题

### 1. 新版模型的本地部署实测

- **显存占用**：7B 模型量化到 Q4_K_M 后约占用 4.2 GB，13B 约 8.1 GB
- **推理速度**：7B 在 RTX 3060 上约 28 tok/s，13B 约 12 tok/s
- 有人提到用 `llama.cpp` 的 `-ngl 32` 参数可以显著提速
- 讨论到上下文长度对显存的影响，128K 上下文会额外占用约 1.5 GB

### 2. RAG 分块策略

群里分享了一篇关于分块大小的对比实验：

| 分块大小 | 检索准确率 | 备注 |
|---|---|---|
| 256 tokens | 71% | 碎片化严重 |
| 512 tokens | 84% | 平衡性最好 |
| 1024 tokens | 79% | 长文档表现好 |

结论是 512 是最佳平衡点，但也要看具体文档类型。

### 3. Docker 端口冲突排查

完整的排查过程：

1. 报错 `Bind for 0.0.0.0:8080 failed: port is already allocated`
2. 用 `netstat -ano | findstr :8080` 找到占用进程
3. 确认是之前没清理的容器，`docker ps -a` 找到后 `docker rm -f`
4. 重启后正常
