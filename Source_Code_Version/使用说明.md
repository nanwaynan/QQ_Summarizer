# QQ 群聊总结器 —— 源码版 使用说明

> **这一版适合谁**：想改代码、或想自己打包 exe 的人。
> 如果你只想用，请选 `Bat_Startup_Version`，那个不需要装 Python。

---

## 使用步骤

### 第 1 步：安装 Python

- 下载地址：<https://www.python.org/downloads/>
- 推荐版本：**3.12**（本程序开发验证于 3.12.9）
- 安装时务必勾选 **Add Python to PATH**

验证是否装好：

```bat
python --version
:: 应输出 Python 3.12.x
```

### 第 2 步：双击「安装依赖.bat」

脚本会自动：

1. 检查 Python 是否可用（依次尝试 `py -3.12`、`py -3`、`python`、常见安装路径）
2. 在本目录创建 `.venv` 虚拟环境
3. 安装 `requirements.txt` 里的依赖

需要联网，约 2-5 分钟。失败时会给出具体原因。

### 第 3 步：双击「启动.bat」

程序界面会打开。首次启动弹三步引导，按提示操作。

---

## ⚠️ 重要：这一版没有内置 NapCat

NapCat 是拉取 QQ 消息必需的中间件。源码版不包含它，你有两个选择：

### 选择 A（推荐）：直接用另外两个版本

`Bat_Startup_Version` 内置了 `napcat_green`（NapCat 精简绿色版），直接复制过来即可。

### 选择 B：自己准备 NapCat

把 `napcat_green` 文件夹放到本目录（或上级目录），程序会自动探测。

也可以用环境变量指定：

```bat
set QQSUMMARIZER_NAPCAT_DIR=D:\your\napcat\dir
```

如果你的电脑上已经装了官方 NapCat（常见位置 `C:\NapCat\shellXXXXX`），程序也能自动找到。

## 目录说明

| 路径 | 说明 |
|---|---|
| `app\` | 程序主体源码 |
| `main.py` | 图形界面入口 |
| `cli.py` | 命令行入口（批量 / 调试用） |
| `tools\make_icon.py` | 工具：图片转多尺寸图标 |
| `tools\make_napcat_green.py` | 工具：生成 NapCat 精简绿色版 |
| `build.spec` | 打包配置（文件夹版） |
| `build_onefile.spec` | 打包配置（单文件版，可选） |
| `requirements.txt` | 依赖清单 |
| `config.example.json` | 配置模板（首次运行自动生成 `config.json`） |
| `安装依赖.bat` | 环境准备 |
| `启动.bat` | 启动程序 |

### 关于图标文件

本版**不含** `app.ico` / `app_icon.png`。

- 运行源码时：程序用内置的默认图标，功能不受影响
- 自己打包时：PyInstaller 会用默认图标（`.spec` 里已做容错处理）

如果你想用自己的图标，把 `app.ico`（建议 6 个尺寸：16/32/48/64/128/256）放到本目录即可。

## 配置在哪改

程序界面 → 左侧「设置」页。

| 配置项 | 填什么 |
|---|---|
| 接口地址（Base URL） | 如 `https://api.openai.com/v1` |
| 模型名称 | 如 `gpt-4o-mini` |
| API Key | **必填**，填你自己的 |

改完点「保存设置」，立即生效，无需重启。

## 常见问题

### 双击启动.bat 提示「未找到 Python 虚拟环境」

先双击「安装依赖.bat」。

### 安装依赖.bat 提示「未找到 Python」

Python 没装，或安装时没勾 "Add Python to PATH"。重新安装 Python 并勾选该项。

### 界面打开了，但服务状态是红点

NapCat 没运行。这一版没有内置 NapCat，请用内置 NapCat 的版本，或自行准备并放到本目录。

### 总结时报 API 错误

到「设置」页点「测试连接」，确认 Base URL、模型名、API Key 三项都正确，且账户有额度。

### 图片很少或没有

你的模型可能不支持视觉输入（多模态）。可以改用支持图片的模型，或在设置里把「总结模式」改为「仅文字」跳过图片处理。
