# 这个版本的可执行文件在哪

本目录只包含**文档、配置模板、启动脚本**，不含 exe 与 NapCat。

## 获取可执行文件

请到本仓库的 **Releases** 页面下载对应压缩包：

| 文件 | 大小 | 内容 |
|---|---|---|
| `EXE_Single_File_Version.zip` | 约 55 MB | 本版本完整包（含 exe + napcat_green） |

下载后解压，会得到一个完整目录，双击其中的 `启动.bat` 即可运行。

## 为什么 exe 不放进仓库

- 单个文件 48-117 MB，每次改动都会让仓库体积翻倍
- 二进制文件无法做 diff，不利于协作
- GitHub 对单文件有 100 MB 硬限制

所以采用业界惯例：**源码入库，二进制走 Releases**。

## 目录对照

本目录的内容 = 压缩包里除 `exe` / `_internal` / `napcat_green` 之外的其余文件。
如果你已经下载了完整的 zip，本目录内容可以忽略。
